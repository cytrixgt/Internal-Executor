# Internal-Executor

A Roblox executor inside of a roblox executor! Pretty cool >w<

---

## How To Use:

1. Copy This Loadstring: ```loadstring(game:HttpGet("https://vellum.rest/VellumInternalExec.luau"))()```
2. Paste it into your executor (Compatible with ALL executors)
3. Have fun!
